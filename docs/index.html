Apple Calendar,
from the terminal

Full-featured CLI for managing Apple Calendar on macOS. Create, update, search, export, and automate events — with structured JSON output built for agents.

macOS only  ·  MIT License  ·  github.com/gopaljigaur/accli

Reference

Commands

All commands support --json for structured output. Exit codes: 0 success · 1 runtime · 2 validation · 10 auth.

setup Trigger macOS Calendar permission prompt. Run once before anything else.
calendars List all calendars with stable IDs, source, and write access. Use IDs, not names.
events List events in a date range. Accepts --from / --to, calendar name or ID, or a saved default.
event Fetch a single event by ID — includes full detail, location, description, and alerts.
create Create an event. Supports --alert (repeatable), --recur, --all-day, location, description.
update Update an event. Supports --dry-run to preview changes without committing them.
delete Delete an event. Supports --dry-run to confirm the target before deleting.
search Search events across all calendars by keyword (summary, location, description). Returns calendar IDs.
export Export all events grouped by calendar. Suitable for backup and sync workflows.
freebusy Show busy time slots in a range. Useful for scheduling and availability checks.
config Set, show, or clear the default calendar saved to ~/.acclirc.

Automation

Built for agents

Every command returns structured JSON, distinct exit codes, and machine-readable error codes — so agents can act on results without parsing text.

$accli search --query "standup" --from 2025-06-01 --to 2025-06-30 --json
{ "events": [{ "id": "abc123", "summary": "Daily standup", ... }], "count": 20 }
$accli update Work abc123 --summary "Standup (rescheduled)" --dry-run --json
{ "dryRun": true, "wouldUpdate": { "changes": { "summary": "Standup (rescheduled)" } } }
$accli create Work --summary "Sync" --start 2025-06-10T10:00 --end 2025-06-10T10:30 --alert 5 --alert 15 --recur weekly --json
{ "ok": true, "event": { "id": "xyz789", "alerts": [5, 15], "isRecurring": true } }
$accli export --from 2025-01-01 --to 2025-12-31 --json
{ "calendars": [...], "totalEvents": 342, "truncated": false }
